# `/resume` 项目导航

## 变更内容

PR #669 使每个工作目录中的会话都可在 `/resume` 中使用。本次后续改动将这些历史记录呈现为双列导航器，而不是把其他项目的会话追加到当前项目会话下方：

- **项目**列显示简洁的文件夹名称，当前工作目录排在最前，其后是其他项目，按各自最近一次建立索引的会话排序。
- **最近会话**只显示所选项目的会话，最新的排在最前；标题会保留所选目录的完整路径。
- Left 将导航移至项目；Up/Down 更改项目并立即更新其会话列表；Right 返回会话；Enter 恢复会话。
- 点击项目会打开其会话列表，而不会恢复任何内容。
- 搜索保持输入焦点，并在所选项目内按名称/模型过滤。

两列共享一个外部浏览器边框和一条分隔线，与 Finder 连续列视图一致，而不是呈现为独立面板。活动列使用强调色标题。当前项目带有标记，项目行省略会话计数，会话列表保留横向留白。

## 架构

此功能完全保留在 `tau_coding.tui.app.SessionPickerScreen` 中。会话存储、索引以及可移植的 `tau_agent` harness 均未改变。选择器从会话管理器提供的记录中推导规范化项目路径，并保留现有的当前项目优先和按最近时间排序规则。

## 验证

自动化 Textual pilot 测试覆盖键盘列切换、项目点击、项目内搜索、空项目、重复列表刷新、边界导航和会话恢复。

手动检查：

1. 在一个其他位置也有会话历史的项目中打开 `/resume` 或按 Ctrl+R。
2. 确认初始显示当前项目的最近会话。
3. 按 Left，然后使用 Up/Down 预览其他项目的会话。
4. 按 Right，选择一个会话，再按 Enter 恢复。
5. 确认输入内容只过滤所选项目的会话，并且 Escape 会关闭界面而不恢复会话。
